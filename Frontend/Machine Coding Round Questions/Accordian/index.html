HTML (HyperText Markup Language) is used to create the structure of a webpage. It defines elements such as headings, paragraphs, images, links, and forms.

CSS (Cascading Style Sheets) is used to style and design webpages. It controls colors, layouts, spacing, fonts, and responsive design.

JavaScript adds interactivity to webpages. It can handle user events, update the DOM, fetch data from APIs, and create dynamic user experiences.
